# * Retrieval coverage is not merely a weak proxy for accuracy here, it is
#   inverted. kinds=fact has the best cov@100 (.961) and the worst accuracy
#   (.5625); raw-first has the worst cov@20 (.609) and nearly the best accuracy.
# * The lexical channel contributes almost nothing. "dense + raw-first" returns
#   the identical 100 memories as dense in a different order, with no BM25, no
#   index and no extra call, and reaches .6333 against hybrid kinds=raw .6390.
# * Nor is it a context-volume effect: raw-first returns exactly as many
